# Provenance of the translated code

`Types.lean`, `Funs.lean` and `FunsExternal_Template.lean` were generated by
[Aeneas](https://github.com/AeneasVerif/aeneas) from fastcrypto's `merkle`
module at commit `d7822bf97ad31bd866b41f5ae726d188d9d2d033` (branch
`aeneas-merkle-loop`, which replaces iterator chains by index loops so that
Aeneas can translate them), through a small wrapper crate exposing
`build_root` and `inclusion_roundtrip`. The wrapper crate, the Charon/Aeneas
invocation and the original scaffold are Deepak Maram's
`aeneas-merkle` project in `github.com/mskd12/lean-learning`.

The Lean library the generated code builds against is pinned in
`lakefile.lean` to Aeneas nightly `2026.10.08` (commit `aa66752`).

`FunsExternal.lean` is hand-written: it fills the holes left in
`FunsExternal_Template.lean` with concrete models (identity `AsRef`,
`Vec::reserve` as the identity, a fixed string for `alloc::fmt::format`,
`OUTPUT_SIZE = DIGEST_LENGTH`). It contains no axioms.
